Macro Wheel — Privacy Policy

Last updated 19 November 2026

Macro Wheel is a desktop application for Windows. It stores what it knows about your work on your own computer. It has no account system, no telemetry, and no advertising.

What is stored, and where

Everything Macro Wheel knows about your work lives in %APPDATA%\MacroWheel on your machine: your configuration, profiles, actions, hotkeys, scripts, custom icons, preferences and the installed Python packages you have added. None of it is uploaded anywhere. It is not visible to us, and we could not read it if we wanted to.

Licence validation

If you activate a licence, Macro Wheel sends your licence key to Gumroad (api.gumroad.com) to confirm that it is valid, and records the result locally so the application can then run offline. The request contains the licence key and the product it belongs to. It does not contain your name, your email, information about your projects or media, or anything else about your machine.

A licence check that fails — because you are offline, or the service is unreachable — does not stop the application from running. After a successful activation, Macro Wheel keeps working without a connection.

Updates

The installer version of Macro Wheel checks a public release manifest on GitHub for a newer version. That request asks for a static file and contains no personal data.

The Microsoft Store version does not make this request at all. The Store updates it.

Your scripts

Scripts you add are run locally in a Python environment managed by Macro Wheel. Their output stays on your computer. Macro Wheel does not transmit script contents, results or logs.

No telemetry, no analytics, no advertising

Macro Wheel contains no crash reporting, no usage tracking, no analytics SDK and no advertising. It does not collect a device identifier, and it does not profile you.

Children

Macro Wheel is a professional tool for video editing. It is not directed at children and collects no personal information from anyone.

Changes to this policy

If this policy changes, the date above changes with it, and the current version is always at this address.
